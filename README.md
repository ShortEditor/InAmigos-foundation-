# InAmigos Foundation — Awareness Webpage

A responsive static awareness website for **InAmigos Foundation**, showcasing the organization's mission, six flagship initiatives, social impact, and volunteer/donation avenues.

**Live Website**: https://in-amigos-foundation-nu.vercel.app/

**Github source code**: https://github.com/ShortEditor/InAmigos-foundation-

---

## Features

- **Editorial Design**: Clean typography pairing *Playfair Display* with *Hanken Grotesk* on a warm palette.
- **Flagship Programs Showcase**: Dedicated visual sections for Projects SEVA, Bachpanshala, Prakriti, Jeev, Udaan, and Vikas.
- **Social Impact Metrics**: Data-backed impact highlights across 28 states.
- **Interactive Micro-Interactions**: Hover reveals, Ken Burns effects on story cards, and custom button animations.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile with an off-canvas drawer navigation.

---

## Tech Stack

- **HTML5** (Semantic markup & SEO metadata)
- **Tailwind CSS** (Utility classes)
- **Vanilla CSS** (`style.css` for custom animations)
- **Google Fonts** (Playfair Display & Hanken Grotesk)
- **Material Symbols** (Google Icons)
- **Deployment**: Vercel
