## 🌟 Six Flagship Initiatives

1. **Project SEVA** — *Serving Humanity with Compassion*  
   Providing essential food packets, clean water, and winter clothing to vulnerable families, daily-wage earners, and underprivileged communities (50,000+ meals & items distributed).

2. **Project Bachpanshala** — *Nurturing Young Minds*  
   Foundational learning, digital literacy workshops, book drives, and school supply distribution for children in marginalized areas.

3. **Project Prakriti** — *Plant for a Better Tomorrow*  
   Large-scale native tree plantation drives, environmental stewardship, waste management workshops, and eco-friendly agriculture support (20,000+ saplings planted).

4. **Project Jeev** — *Compassionate Animal Welfare*  
   Daily stray feeding drives (50+ animals daily), emergency medical rescue, and reflective safety collar drives.

5. **Project Udaan** — *Empowering Women, Elevating Lives*  
   Fostering female financial independence through rural Self-Help Groups (SHGs), vocational training, and menstrual hygiene awareness.

6. **Project Vikas** — *Skill Development & Youth Empowerment*  
   Career-readiness training in research, content operations, data analytics, and digital outreach (30,000+ student interns trained).

## 🛠️ Technology Stack

- **Markup**: HTML5 (Semantic tags, accessible structure, SEO meta tags)
- **Styling**: Tailwind CSS (Utility-first styling) + Custom Vanilla CSS (`style.css`)
- **Typography**: 
  - *Playfair Display* (Editorial Headlines)
  - *Hanken Grotesk* (Clean Modern Body)
- **Icons**: Google Material Symbols Outlined
- **Micro-Interactions**:
  - Center-outward drawing navigation underlines
  - Diagonal skewed wipe button fills
  - Ken Burns image zoom & color reveal on project stories
  - 3D perspective tilt on initiative cards
  - Dedicated mobile drawer navigation with smooth slide animation
- **Hosting**: Vercel

## 🚀 Local Development

To run the website locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ShortEditor/InAmigos-foundation-.git
   cd InAmigos-foundation-
   ```

2. **Open in browser**:
   Simply open `index.html` in any web browser, or use a local dev server (e.g. VS Code Live Server or `npx serve .`).
